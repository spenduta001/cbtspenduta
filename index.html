Tanamkan URL Web App & Koneksi Google Sheets

URL yang ditanam akan tersimpan otomatis ke Cloud serta dapat diunduh menjadi file HTML siap hosting online (GitHub Pages / Netlify / Vercel / Google Sites).

Cara Meng-onlinekan Web App agar Diakses Guru & Siswa dari HP/Laptop:

Langkah 1: Deploy Code.gs di Google Sheets sebagai Web App (Who has access: Anyone), lalu tempel URL .../exec ke kolom 1 di atas dan klik Tanam & Simpan URL.

Langkah 2: Klik tombol Unduh HTML Tertanam (Siap Hosting) untuk mendapatkan file index.html yang sudah tertanam URL Web App secara permanen di dalam kodenya.

Langkah 3: Unggah file tersebut ke layanan hosting gratis seperti Netlify Drop (app.netlify.com/drop), Vercel, atau GitHub Pages, lalu bagikan Link Ruang Ujian Siswa & Link Portal Guru di atas ke seluruh peserta!
